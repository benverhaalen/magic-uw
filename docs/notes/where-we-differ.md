# Where our research differs from the current plan

**Status: our decisions.** Checked 2026-09-26 against `main` at `73ff7a6` and the [implementation status](../implementation-status.md); rows 3, 11 and 17–21 updated 2026-09-26 late against `main` at `8e3cf98` and the [course-backend spec](../plans/2026-09-26-course-backend/spec.md) v8. Where a row depends on an open human call, it's marked `(open: H<n>)` and listed in [plan §9](../plans/2026-09-26-course-backend/plan.md#9-open-human-calls). Each row says what's built today, **what we decided** where the research found a better option for quality, efficiency or cost, the evidence, and how we'll verify it. The decisions stand on their evidence. Code in the shared packages changes through PRs the team merges, and rows marked *measure first* are the only genuinely open ones.

## Where we agree (no change proposed)
- We run no developer account of our own for the student's AI. Prompt caching is used where the client does it for the student (the warm session read the course prefix from cache at 0.1×, [plan D38](../plans/2026-09-26-course-backend/plan.md)); a batch discount applies only on the student's own key, and P9 measures it (M7).
- Code handles exact facts, Jev makes bounded judgments, and a model is never an authorization.
- Local-only by default; the exact payload is previewed before anything is sent.
- The utility-process worker, FTS5 search, the judgment cache keyed by input hash, versioned captures, and partial-capture safety are all built, and the research supports each of them.
- Course policy first; coach when the policy is vague or silent.
