# Where our research differs from the current plan

**Status: our decisions.** Checked 2026-09-26 against `main` at `73ff7a6` and the [implementation status](../implementation-status.md). Each row says what's built today, **what we decided** where the research found a better option for quality, efficiency or cost, the evidence, and how we'll verify it. The decisions stand on their evidence. Code in Ben's packages changes through PRs he merges, and rows marked *measure first* are the only genuinely open ones.

Labels: **built** (in the code today) · **proposed** · **evidence** (with its source).

## Where we agree (no change proposed)
- Hosted prompt caching and batch APIs are **not** pursued. They need a developer account, which the decided account model rules out.
- Code handles exact facts, Jev makes bounded judgments, and a model is never an authorization.
- Local-only by default; the exact payload is previewed before anything is sent.
- The utility-process worker, FTS5 search, the judgment cache keyed by input hash, versioned captures, and partial-capture safety are all built, and the research supports each of them.
- Course policy first; coach when the policy is vague or silent.
