# Backend lane status: what works, how it was measured, what doesn't (September 27, morning)

Owner: Nathaniel's backend lane. It's written so the team can pull, run and fix. Labels:
- **measured (synthetic):** a number from a repo test or harness on synthetic data
- **measured (live-shaped):** a read-only copy of a real workspace (numbers only, no content)
- **built:** passes its tests, not run live
- **broken / open:** known not working

## How to get it
- **Backend wave 1 is PR #51 (`integrate/backend-0927`),** 16 branches merged with a merge commit. If it isn't merged yet when you read this, pull that branch.
  - CI: the first run failed on four Windows-only client-detection scenarios that also ran on Linux. They're now gated to the Windows runner (`4348752`), and it merges on green.
- **Wave 2 branches are pushed but not merged** (table below). Pull the one you're fixing.
- **After pulling:** quit the app, run `pnpm install` if the lockfile changed, then `pnpm dev`. A running app never picks up new code.

## Known broken or open (please take)
1. **Tab and view opening is slow.** Measurement and fixes are in progress on `wave/backend-0927b` (the learning-ops batch resolver, commands returning deltas instead of the full snapshot, batch graph reads, stale-while-revalidate).
2. **Outlook** has never run live: it needs a registered Microsoft app (client ID) or a decision to use the UW web session. Google Docs needs a Google OAuth client. Jev needs a hosted gateway (`MAGIC_GATEWAY_URL`); the key is in GitHub secrets as `TYPESAFE_API_KEY`.
3. **No Ctrl+K or dictation binding on main.** The voice module is on `feat/floating-chat`, ready for Ben's launcher mic.
4. **Security gaps found by code reading** (not yet fixed):
   - answer sentences aren't bound to their cited quotes (`core/intent/ask.ts`)
   - outside mail naming a course code is labelled "Course staff" (`connectors/graph.ts`)
   - Jev can promote an unknown sender to urgent
   - a student-posted link can become a synced course site (`core/site-triage.ts`)
5. **Two wall-clock tests** (derive stretch, mastery median) fail under full-suite load locally; they report only on CI.
6. **Not verified live:** that the Canvas sign-in session also works for Course Search & Enroll.
