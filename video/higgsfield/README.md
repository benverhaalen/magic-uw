# Higgsfield demo video — prompts, assets and timeline

**Status (September 27, Aidan + Claude):** prompt package and assets prepared; clips not yet generated. This
records the decisions from the Higgsfield prompt-engineering session so the edit can be picked up by anyone.
It is a proposal for the animated segments, not a replacement for [`../story.md`](../story.md) or
[`../script.md`](../script.md).

## Decisions and why

| Decision | Reason |
| --- | --- |
| Wiz animates on his own green-screen layer; screens are separate stills; the editor composites | Aidan's hard constraint: Wiz "has to be able to move freely and should never change size". Zooms happen on the screen layer only, so Wiz's scale never changes. |
| Higgsfield clips are in-place (treadmill) with a locked camera; the editor moves the layer along flight paths | Exact timing and position against the voiceover; no model drift in size or path. |
| Wiz poses are built from `marketing/logo-design-elements/svg/mark-color.svg`, not generated | Aidan: "higgsfield should use the svg images in the repo to animate the wizard itself". Uses the SVG's own arm pivots and palette; adds a staff (night cardinal `#5c0b10`, star-yellow `#f7c440` star). All poses share one viewBox, so scale and head position are identical. |
| Staff in the hand on the viewer's left; wave with the other arm | Wiz mostly hovers to the right of what he taps, so the staff points naturally toward the target. |
| Missing screens are rendered from the product's own fonts and colours over the real Home screenshot, not generated by an image model | Aidan: "all created images should look like they are a part of our product using the exact same UI". Image models approximate fonts, icons and text; zoomed frames would expose that. |
| Model: Kling 3.0 image-to-video, start + end frame, 5 s, 16:9, 1080p (Wan as fallback) | Higgsfield's guide describes Kling as built for multi-shot continuity and Wan for first/last-frame control; Seedance has no start frame, so clips can't chain. From Higgsfield docs, not tested on Wiz. |
| Frames 1, 5, 12 are live camera footage | Higgsfield ignores them or leaves black filler of the right length. |
| Frame 3 taps "Open assignment" on the ENGL 177 Daily Brief item | Matches the Frame 4 split screen (ENGL 177 course page + Bök PDF). |
| AI policy page is a short summary from conduct.students.wisc.edu; CS 400 is not added to the sidebar | Aidan's direction. Page header says COMPSCI 400; sidebar stays as Home shows it. |
| Voiceover claims describing future capability stay as recorded | Aidan: "we are allowed to talk about potential". |

## Higgsfield clips

Settings for every clip: Kling 3.0, image-to-video, start and end frame, 5 s, 16:9, 1080p, camera static.
Prefix every prompt with:

```
Flat 2D vector cartoon animation, smooth puppet-style motion like a clean motion-graphics mascot. Camera is
completely static and locked off: no zoom, no pan, no dolly, no rotation. Wiz stays the exact same size the entire
clip; his head stays in the same place unless the action below says otherwise. Flat #00FF00 background for the
whole clip. Keep the character design, colors, outlines and proportions identical to the start frame at every
moment. Front-facing only; no 3D turning.
NEGATIVE: 3D, shading, gradients, realistic, fingers, extra limbs, size change, zoom, camera movement,
background change, shadows, floor, text, morphing, extra characters, motion blur.
```

| Clip | Start → end | Prompt |
| --- | --- | --- |
| H1 Idle loop | idle → idle | 0–5 s: floats in place, two gentle bobs (≈3% of frame height). Robe hem and beard sway; staff sways slightly. One quick blink at 3.0 s. Two tiny star-yellow sparkles twinkle by the staff star. Ends on the start pose. |
| H2 Fly loop | fly → fly | 0–5 s: flies in place like a treadmill, body fixed in frame, tilted left. Hat tip, beard, robe hem and legs flutter to the right; small star-yellow sparkles stream from the staff star and hem toward the right edge. Slight bob. Ends on the start pose. |
| H3 Wave | idle → idle | 0–0.5 s: raises the free mitten (viewer's right) beside his head. 0.5–2.3 s: waves side to side three times, pivoting at the shoulder, small happy bounce. 2.3–2.8 s: lowers it. 2.8–5 s: idle float. |
| H4 Staff tap | idle → idle | 0–0.6 s: leans slightly left, lifts the staff. 0.6–1.0 s: thrusts the staff down to the viewer's left. At 1.0 s the star tip touches an invisible point, flashes and releases 6–8 star-yellow sparkles and one thin expanding yellow ring. 1.0–1.6 s: holds. 1.6–2.3 s: returns upright. 2.3–5 s: idle. (`wiz-tap.png` shows the contact pose; use it as the end frame on Wan if Kling misses it.) |
| H5 Land | fly → idle | 0–1.0 s: slows and straightens upright; robe, beard and hat settle; sparkles fade. 1.0–5 s: idle float. |
| H6 Take-off | idle → fly | 0–0.8 s: small crouch, tilts left into the flying pose, sparkles begin. 0.8–5 s: flies in place. |
| H7 Poof | green → green | No character. 0–0.5 s: cartoon burst from center — star-yellow stars, cream sparkles, round cream smoke puffs with warm-ink `#29231f` outlines — filling 80% of frame at 0.6 s. 0.6–1.6 s: drift outward and fade to flat green. 1.6–5 s: empty green. |

In the edit, use only the needed part of each clip (e.g. first 1.0 s of H5, then H1). Mirror H4 when a target
is on Wiz's right. If the keyer eats the yellow sparkles, regenerate on flat blue `#0047BB`.

## Higgsfield MCP

`claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp` adds the server to the
user config (not the repo). It needs a one-time sign-in: run `claude mcp login higgsfield` (or `/mcp` →
higgsfield → Authenticate) and click Allow on Higgsfield's consent page, which requests `openid`, `email` and
`offline_access` for Claude Code. Sessions started before the sign-in don't see the tools; start a new one. A
Higgsfield connector added on claude.ai did not appear in the already-running desktop session.
