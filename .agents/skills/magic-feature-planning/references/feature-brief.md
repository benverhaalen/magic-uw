# Compact feature brief

Use this in existing task notes for sustained work. Resolve repo paths from the discovered root. Private operational notes belong in an established private scratch area, not a new committed tracking system. Omit fields that add no decision value; link evidence instead of copying transcripts.

- **Outcome / why now / authority:** student benefit, audience, requested mode and authorized scope; accepted decisions versus proposals.
- **Baseline:** entry/default, code and relevant branch/revision, existing reusable capability; missing/partial/unconnected/unverified with evidence and freshness limits.
- **Context:** actually captured course/professor/student evidence, field meaning, coverage/freshness/conflicts, permitted destinations, unknowns, correction path, and the specific choice each decisive input changes. Record the useful inference and its limit; check what changes when evidence is missing.
- **Journey:** normal entry → useful action → result → return/resume; meaningful success, cancellation and relevant failures. Name the reduction in setup or management effort.
- **Selected form and mechanism:** alternatives considered, inspected reference property, why it fits, actual change and failure/reversal condition.
- **Bounded architecture:** existing store/session/runtime ownership, data flow and consumer, code/retrieval/Jev/model/tool responsibilities, policy/consent/provenance, cost/latency and invalidation.
- **Scope and acceptance:** deliverables and non-goals; each important requirement mapped to the producing operation and observable check. Dependencies and untested assumptions.
- **Result / next decision:** evidence of actual behavior, material remaining limits, corrections and reasons, and the next useful step.

For an inventory request, a compact comparison of capability, actual state, evidence, student benefit, and next step is usually enough. For an exploration request, give a recommendation and a buildable brief without silently implementing it. During implementation, keep the brief current when feedback changes the objective or constraints.
